# Chosen Tours & Travel

Refreshed static website, based on the original Chosen Tours demo. Open `index.html` directly, or run:

```powershell
python -m http.server 4175 --bind 127.0.0.1
```

Preview: http://127.0.0.1:4175

Files: `index.html`, `styles.css`, `app.js`. No build or package installation is required. Photography and fonts use external Unsplash and Google Fonts URLs.

The trip planner prepares a WhatsApp enquiry for +256 704 598 459. Visitors review and send the message in WhatsApp. This site does not store enquiries, process bookings or payments, or submit visa applications.
